# LetterMate｜多源智能信息发现平台

**项目类型：** 个人项目 / 核心开发

## 项目介绍

面向开发者与技术学习者的**智能信息发现平台**，通过**多源检索、证据校验与个性化排序**，将分散的技术内容整理为可追溯的 Feed 与研究简报。

## 技术栈

TypeScript、React、NestJS、BullMQ、Redis、PostgreSQL、Prisma、OpenRouter、Prometheus、Docker

## 项目亮点

- **智能发现系统：** 针对宽泛搜索噪声和精确版本误匹配问题，构建 Topic 监控、Trend 发现和 Creator 订阅三类管线；通过**完整关键词边界、正文补全、事实支持、历史增量与近似去重**，保证 Feed 内容有来源、有增量。

- **多源检索系统：** 为统一接入不同平台，设计 **Connector 适配器与 Source Router**，覆盖搜索、社交、Feed、视频、代码和论文等十余类来源；采用**并发检索、故障隔离与 SSRF 安全抓取**，提升内容覆盖率并避免单一来源异常中断任务。

- **AI 生成系统：** 按关键词扩展、质量评审、中文生成等任务使用 **Fast / Quality / Localization 模型路由**，并限制单次运行的调用次数、Token 和成本；模型仅返回稳定引用 ID，服务端通过 **Zod Schema 与引用白名单**校验，避免生成无来源内容。

- **个性化 Feed：** 合并 Topic、Trend、Creator 内容并进行跨来源去重，基于订阅和“感兴趣 / 减少推荐”反馈构建**持久化兴趣记忆与个性化排序**；设置约 **10% 探索比例上限**并保护主动订阅内容，兼顾内容发现与推荐可控性。

- **异步任务系统：** 使用 **BullMQ + Redis + PostgreSQL** 承载长耗时发现任务，通过**运行租约、幂等重试和 6/12/24 小时自适应调度**处理任务重复、进程中断和无效轮询；使用 **Prometheus** 记录各阶段耗时、失败原因和来源漏斗，便于定位质量与运行问题。
